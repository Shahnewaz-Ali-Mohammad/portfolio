# Developer Portfolio

Personal portfolio for Shahnewaz Ali Mohammad, presenting professional experience, education, technical capabilities, and selected full-stack and agentic AI projects.

## Built with

- Next.js
- React
- TypeScript
- CSS
- Lucide icons

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Project images

Add final project screenshots to `public/projects` using the filenames documented in that folder.
